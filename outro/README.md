# outro/

Put your fixed **4-second outro** video here as `outro.mp4`.

- 1080x1920 (9:16) preferred, ~4s and a pre-made `.mp4` clip (appended verbatim).
- The reel renderer crossfades (~0.4s) from each reel's content into this outro
  and fades the audio out around the transition.
- Committed so the Colab notebook can fetch it via raw.githubusercontent.
